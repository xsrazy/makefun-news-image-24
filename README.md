front page drawn with PIL (see `draw.py`), with the day's lead story, four
supporting stories and a ticker. `main.ts` copies the finished `entry.png`
to the output directory.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
